# Frijterz Legal

Static privacy and terms pages for the private Frijterz personal finance
dashboard. The site contains no analytics, cookies, external assets, dashboard
code, credentials, or financial data.

## Documents

- `privacy/index.html` — Privacy Notice
- `terms/index.html` — Terms of Use

## Publish with GitHub Pages

1. Create a separate public GitHub repository named `frijterz-legal`.
2. Commit and push the contents of this directory to its `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, `main`, and
   `/ (root)`.

After GitHub publishes the site, the Enable Banking application URLs will be:

```text
https://jetpaction.github.io/frijterz-legal/privacy/
https://jetpaction.github.io/frijterz-legal/terms/
```

Review the wording before publication. Update the notice before requesting
transaction history, introducing cloud storage or analytics, or allowing anyone
else to use the application.
